# ADR 0025: Name the product Shroudly

**Status:** Accepted

## Context

The prior product name is tied to a legacy demonstration, while naming the
replacement after another project could imply an official affiliation that has
not been established. A collision check found unrelated commercial and active
software uses of the Shroudly name.

## Decision

Unconditionally name the Midnight-native product **Shroudly** and accept the known name-collision risk without making trademark or domain clearance a Preprod release gate. Describe it as a private prize-savings application inspired by the general prize-savings model. Do not imply that it is operated, endorsed, audited, or deployed by PoolTogether.

## Consequences

Active application metadata, package names where practical, page titles,
accessible labels, documentation, screenshots, deployment names, evidence
manifests, status pages, and runbooks use Shroudly. Historical material retains
its original label and is clearly marked legacy. The accepted collision can
cause domain, discoverability, marketplace, or legal friction and remains an
explicit Operator risk. It does not waive the separate Mainnet legal gate for
accepting real value.
